# API Contract — Earth-Titan Fitness

This document specifies the REST API contract for **Earth-Titan Fitness** (built with `json-server` in Weeks 4–5 and replaced by the real Express/Node backend in Weeks 6–7, with JWT authentication added in Week 8).

- **Base URL (development):** `http://localhost:3000` (or `/api` in Weeks 6–7)
- **Content-Type:** `application/json`

---

## 1. Resources and Fields

Every resource matches the entities and constraints defined in [`PROPOSAL.md`](../PROPOSAL.md) and [`db.json`](./db.json).

### 1.1 `users`

Represents all accounts in the system: gym customers, front-desk employees/cashiers, and administrators.

| Field      | Type               | Required           | Rules / Constraints                                                                                        |
| ---------- | ------------------ | ------------------ | ---------------------------------------------------------------------------------------------------------- |
| `id`       | `number` (integer) | Auto (PK)          | Positive integer generated by the server (`>= 1`).                                                         |
| `name`     | `string`           | Required           | `2–60` characters; letters, spaces, `.`, `'`, `-` only (`^[A-Za-z][A-Za-z .'-]*$`).                        |
| `email`    | `string`           | Required           | Unique, lowercase valid email address (`<= 120` chars).                                                    |
| `password` | `string`           | Required on create | Input only: `6–72` characters. Stored as `password_hash` in Weeks 6–8 and **never** returned in responses. |
| `role`     | `string` (enum)    | Required           | One of `'customer'`, `'employee'`, `'admin'`.                                                              |

---

### 1.2 `memberships`

Represents a customer's gym subscription.

- **Relationship:** Each membership belongs to one user via `userId` (`1:0..1` with `users`, unique per user).
- **Branch scope:** A membership is valid across **all** Earth-Titan Fitness branches (no `branchId` foreign key).

| Field              | Type                | Required      | Rules / Constraints                                                                                                                  |
| ------------------ | ------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `id`               | `number` (integer)  | Auto (PK)     | Positive integer generated by the server (`>= 1`).                                                                                   |
| `userId`           | `number` (integer)  | Required (FK) | References `users.id`. Unique (one membership per user).                                                                             |
| `membershipCode`   | `string`            | Required      | Unique card/pass code matching `^ETF-\d{5}$` (e.g., `"ETF-89241"`), `9` characters.                                                  |
| `plan`             | `string` (enum)     | Required      | One of `'Titan Pro Black'`, `'Titan Standard Iron'`, `'Titan Month-to-Month'`.                                                       |
| `registrationDate` | `string` (ISO date) | Required      | Format `YYYY-MM-DD`; cannot be in the future (`<= today`).                                                                           |
| `expirationDate`   | `string` (ISO date) | Required      | Format `YYYY-MM-DD`; must be strictly after `registrationDate` (`> registrationDate`).                                               |
| `status`           | `string` (enum)     | Required      | One of `'active'`, `'expired'` (derived from `expirationDate` vs. current date; UI also flags `'expiring'` when `0–14` days remain). |

---

### 1.3 `branches`

Represents physical Earth-Titan Fitness gym locations, their regular hours, amenities, and national holiday schedules.

| Field                | Type               | Required  | Rules / Constraints                                                                            |
| -------------------- | ------------------ | --------- | ---------------------------------------------------------------------------------------------- |
| `id`                 | `number` (integer) | Auto (PK) | Positive integer generated by the server (`>= 1`).                                             |
| `name`               | `string`           | Required  | Unique branch name, `3–80` characters.                                                         |
| `address`            | `string`           | Required  | Street address, `5–160` characters.                                                            |
| `image`              | `string`           | Optional  | Asset filename or URL (`<= 255` characters, defaults to `"branch1-1.png"`).                    |
| `badge`              | `string`           | Optional  | Short station label, `2–30` characters (e.g., `"HQ Node 01"`).                                 |
| `openingTime`        | `string` (time)    | Required  | Weekday opening time in 24-hour `HH:mm` format (`00:00`–`23:59`).                              |
| `closingTime`        | `string` (time)    | Required  | Weekday closing time in 24-hour `HH:mm` format (`> openingTime` unless `is24Hours` is `true`). |
| `weekendOpeningTime` | `string` (time)    | Required  | Weekend (`Sat–Sun`) opening time in `HH:mm` format.                                            |
| `weekendClosingTime` | `string` (time)    | Required  | Weekend (`Sat–Sun`) closing time in `HH:mm` format.                                            |
| `is24Hours`          | `boolean`          | Required  | `true` if open 24/7, `false` otherwise.                                                        |
| `capacityPercent`    | `number` (integer) | Required  | Live capacity percentage, range `0–100`.                                                       |
| `amenities`          | `Amenity[]`        | Optional  | Array of `{ icon: string (1–40 chars), label: string (2–50 chars) }` (`0–12` items).           |
| `holidaySchedule`    | `HolidayEntry[]`   | Optional  | Array of holiday overrides (see rules below).                                                  |

**`HolidayEntry` object fields:**

| Field         | Type                | Required | Rules / Constraints                                                    |
| ------------- | ------------------- | -------- | ---------------------------------------------------------------------- |
| `date`        | `string` (ISO date) | Required | Format `YYYY-MM-DD`.                                                   |
| `name`        | `string`            | Required | Holiday name, `2–60` characters (e.g., `"Thanksgiving Day"`).          |
| `type`        | `string` (enum)     | Required | One of `'regular'`, `'adjusted'`, `'closed'`.                          |
| `openingTime` | `string` (time)     | Optional | Required when `type === 'adjusted'`; `HH:mm` format.                   |
| `closingTime` | `string` (time)     | Optional | Required when `type === 'adjusted'`; `HH:mm` format (`> openingTime`). |

## 2. Endpoints

| Method                          | Path               | Request Body / Query                                                                                                                                            | Success Status & Response                               | Error Statuses                                                                                                                                                                                             |
| ------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Auth (Week 8)**               |                    |                                                                                                                                                                 |                                                         |                                                                                                                                                                                                            |
| `POST`                          | `/auth/login`      | `{ email, password, role, gymId? }`                                                                                                                             | `200 OK` — `{ token, user: { id, name, email, role } }` | `400` invalid fields, `401` wrong email/password/gymId, `403` role mismatch                                                                                                                                |
| `GET`                           | `/auth/me`         | — (Bearer token header)                                                                                                                                         | `200 OK` — `{ id, name, email, role }`                  | `401` missing/expired token                                                                                                                                                                                |
| **Branches (`branches`)**       |                    |                                                                                                                                                                 |                                                         |                                                                                                                                                                                                            |
| `GET`                           | `/branches`        | Optional query: `?q=`                                                                                                                                           | `200 OK` — `GymBranch[]`                                | `500` server error                                                                                                                                                                                         |
| `GET`                           | `/branches/:id`    | —                                                                                                                                                               | `200 OK` — `GymBranch`                                  | `400` invalid id, `404` branch not found                                                                                                                                                                   |
| `POST`                          | `/branches`        | `{ name, address, image?, badge?, openingTime, closingTime, weekendOpeningTime, weekendClosingTime, is24Hours, capacityPercent, amenities?, holidaySchedule? }` | `201 Created` — created `GymBranch`                     | `400` validation failed, `401` not logged in, `403` not admin, `409` duplicate name                                                                                                                        |
| `PATCH`                         | `/branches/:id`    | Partial `GymBranch` fields (e.g., `{ openingTime, closingTime, holidaySchedule }`)                                                                              | `200 OK` — updated `GymBranch`                          | `400` validation failed, `401` not logged in, `403` not admin, `404` branch not found                                                                                                                      |
| `DELETE`                        | `/branches/:id`    | —                                                                                                                                                               | `204 No Content`                                        | `401` not logged in, `403` not admin, `404` branch not found                                                                                                                                               |
| **Users (`users`)**             |                    |                                                                                                                                                                 |                                                         |                                                                                                                                                                                                            |
| `GET`                           | `/users`           | Optional query: `?role=customer` or `?email=`                                                                                                                   | `200 OK` — `User[]` (without `password`)                | `401` not logged in, `403` not admin                                                                                                                                                                       |
| `GET`                           | `/users/:id`       | —                                                                                                                                                               | `200 OK` — `User` (without `password`)                  | `401` not logged in, `403` forbidden, `404` user not found                                                                                                                                                 |
| `POST`                          | `/users`           | `{ name, email, password, role }`                                                                                                                               | `201 Created` — created `User`                          | `400` validation failed, `401` not logged in, `403` not admin, `409` email already exists                                                                                                                  |
| `PATCH`                         | `/users/:id`       | `{ name?, email?, role? }`                                                                                                                                      | `200 OK` — updated `User`                               | `400` validation failed, `401` not logged in, `403` not admin, `404` user not found, `409` duplicate email                                                                                                 |
| `DELETE`                        | `/users/:id`       | —                                                                                                                                                               | `204 No Content`                                        | `401` not logged in, `403` not admin, `404` user not found                                                                                                                                                 |
| **Memberships (`memberships`)** |                    |                                                                                                                                                                 |                                                         |                                                                                                                                                                                                            |
| `GET`                           | `/memberships`     | Query: `?_expand=user`, `?userId=`, `?membershipCode=`, `?status=`, `?_page=&_limit=`                                                                           | `200 OK` — `MembershipWithUser[]`                       | `401` not logged in, `403` forbidden (customers may only query their own `userId`)                                                                                                                         |
| `GET`                           | `/memberships/:id` | Optional query: `?_expand=user`                                                                                                                                 | `200 OK` — `MembershipWithUser`                         | `401` not logged in, `403` not owner/staff/admin, `404` membership not found                                                                                                                               |
| `POST`                          | `/memberships`     | `{ userId, membershipCode, plan, registrationDate, expirationDate, status }`                                                                                    | `201 Created` — created `Membership`                    | `400` validation failed (e.g. `expirationDate <= registrationDate`), `401` not logged in, `403` not admin, `404` `userId` not found, `409` duplicate `membershipCode` or `userId` already has a membership |
| `PATCH`                         | `/memberships/:id` | `{ membershipCode?, plan?, registrationDate?, expirationDate?, status? }`                                                                                       | `200 OK` — updated `Membership`                         | `400` validation failed, `401` not logged in, `403` not admin, `404` membership not found, `409` duplicate `membershipCode`                                                                                |
| `DELETE`                        | `/memberships/:id` | —                                                                                                                                                               | `204 No Content`                                        | `401` not logged in, `403` not admin, `404` membership not found                                                                                                                                           |

### Standard Error Response Body (Weeks 6–7)

```json
{
  "error": "Validation failed",
  "details": {
    "email": "This email already belongs to another member.",
    "expirationDate": "Expire date must be after the register date."
  }
}
```

## 3. Authentication & Role Matrix (Planned for Week 8)

### 3.1 API Endpoints

| Endpoint                                                                 | Login Required? | Allowed Roles                                       | Notes                                                                                                                 |
| ------------------------------------------------------------------------ | --------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `POST /auth/login`                                                       | No (Public)     | Everyone                                            | Exchanges credentials for a signed session/JWT.                                                                       |
| `GET /auth/me`                                                           | Yes             | `customer`, `employee`, `admin`                     | Returns the currently authenticated user.                                                                             |
| `GET /branches`, `GET /branches/:id`                                     | No (Public)     | Everyone                                            | US-01: anyone can browse gym locations, regular hours, and holiday schedules.                                         |
| `POST /branches`, `PATCH /branches/:id`, `DELETE /branches/:id`          | Yes             | `admin`                                             | Only administrators can add, update, or remove branches and holiday schedules.                                        |
| `GET /memberships?userId=:me`                                            | Yes             | `customer` (own `userId` only), `employee`, `admin` | US-02 & Constraint #7: customers can only read their own membership; accessing another member's record returns `403`. |
| `GET /memberships?membershipCode=...&_expand=user`                       | Yes             | `employee`, `admin`                                 | US-03 & US-04: front-desk staff verify a customer's identity and expiration status by Gym ID.                         |
| `GET /memberships?_expand=user` (full list)                              | Yes             | `employee`, `admin`                                 | US-08 & Stretch (search + pagination): full registry list for staff and admins.                                       |
| `POST /memberships`, `PATCH /memberships/:id`, `DELETE /memberships/:id` | Yes             | `admin`                                             | US-08: only administrators can create, update, or delete membership records.                                          |
| `GET /users`, `POST /users`, `PATCH /users/:id`, `DELETE /users/:id`     | Yes             | `admin`                                             | US-08: only administrators manage user accounts.                                                                      |
